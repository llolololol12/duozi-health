# DUOZI Health — Premium OEM & ODM Supplement Manufacturer Website

A clean, high-end B2B product showcase built for overseas buyers, importers and brand owners.
Built with **React 18 + Vite + Tailwind CSS**, ready to deploy on **Netlify**.

## Features

- Hero banner with OEM/ODM positioning and CTAs
- Product category cards (Beauty, Women's Health, Vitamins & Minerals, Sports Nutrition)
- Product grid with **category filter**, **keyword search** and **favorites (saved)** persistence
- Product detail pages with benefits, available forms, OEM service and inquiry CTAs
- "Why Choose Us" GMP / OEM capabilities section
- Contact / inquiry form (Netlify Forms ready)
- Fully responsive (desktop / tablet / mobile)
- Lazy-loaded images, modular components, single data source for products

## Getting started

```bash
# install dependencies
npm install

# start dev server
npm run dev

# production build
npm run build

# regenerate the SVG product images (optional)
npm run assets
```

> Note: the dev/build toolchain uses Node 18+.

## Deploy to Netlify

1. Push this folder to a Git repository (GitHub / GitLab / Bitbucket).
2. In Netlify, click **Add new site → Import an existing project** and select the repo.
3. Netlify auto-detects the settings from `netlify.toml`:
   - Build command: `npm run build`
   - Publish directory: `dist`
4. Click **Deploy**.

The `_redirects` file (and the `netlify.toml` redirect) ensure the product detail pages
(e.g. `/product/marine-collagen`) work as a single-page app on refresh.

### Netlify Forms
The inquiry form in the **Contact** section is wired to Netlify Forms via a hidden static
form in `index.html`. Once deployed, submissions appear under **Site → Forms** in the
Netlify dashboard. To receive email notifications, add a notification for the `inquiry` form.

## Managing products

All products live in `src/data/products.js` as a flat array — one object per product:

```js
{
  id: 'marine-collagen',                 // URL slug
  name: 'OEM Marine Collagen Peptide Powder',
  category: 'beauty',                    // beauty | womens-health | vitamins | sports
  image: '/images/product-marine-collagen.svg',
  shortDescription: '…',                 // one-line selling point
  tags: ['OEM Available', 'Private Label', 'Custom Formula'],
  benefits: ['Supports Skin Elasticity', '…'],
  forms: ['Powder', 'Capsule', 'Tablet', 'Gummy', 'Softgel'],
  oem: true,
  features: ['Factory Direct', 'Low MOQ', 'Custom Packaging'],
}
```

### Importing from an Excel product library
Because `products.js` is a plain array, it is easy to regenerate from a spreadsheet:

1. Export your product list to CSV with columns matching the fields above
   (`id, name, category, image, shortDescription, tags, benefits, forms, oem, features`).
2. Use a short script (or an AI prompt) to map each CSV row into the object shape above.
   Arrays (`tags`, `benefits`, `forms`, `features`) can be split on `;` or `|`.
3. Replace the `PRODUCTS` array in `src/data/products.js`.

### Adding / replacing product images
The current product images are clean SVG illustrations generated by
`scripts/generate-assets.mjs` so the site ships fast and self-contained. To use real
product photography instead:

1. Drop your images into `public/images/` (e.g. `product-marine-collagen.jpg`).
2. Update the `image` field in `src/data/products.js` to the new path.
3. No code changes are required — the card and detail page read `image` automatically.

## Branding / colors
The visual identity uses white + deep teal/green (`#0e7c66`) for a clean, natural,
professional feel. Adjust the palette in `tailwind.config.js` (`colors.brand`) and the
SVG accent colors in `scripts/generate-assets.mjs` (`ACCENTS`).
